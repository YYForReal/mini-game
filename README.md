# 🎮 小游戏项目集

一个（即将）集合各种创意小游戏的仓库，每个游戏都在经典玩法的基础上加入独特的创新元素。

> **创建日期**: 2025年11月11日
> **项目目标**: (Vibe Coding)开发有趣的小游戏，在经典游戏机制上做创新

---

## 🌟 游戏列表

### 1. 🌊 光影之线 (Light Beam)

**位置**: `snake_game/`
**类型**: 创意贪吃蛇 | 粒子特效 | 技能系统

#### 🎯 游戏特色
- **创新题材**: 摆脱传统贪吃蛇设定，控制一道发光的光束在黑暗中穿梭
- **炫酷特效**:
  - 动态粒子系统和光晕效果
  - 收集光点时的爆炸特效
  - 光束渐变色彩和轨迹效果
- **技能系统**:
  - ⚡ **加速模式**: 消耗30能量，速度翻倍5秒
  - 🛡 **能量护盾**: 消耗20能量，保护8秒可反弹碰撞
- **连击机制**: 收集金色光点获得连击奖励
- **多平台支持**: 完美适配键盘、鼠标、触摸屏操作

#### 🎮 游戏玩法
- 控制光束收集蓝色和金色光点
- 避免撞到墙壁或自己的光束轨迹
- 合理使用技能获得高分
- 随等级提升，游戏难度递增

#### 🛠️ 技术亮点
- React 18 + Canvas API 高性能渲染
- 60FPS 流畅游戏体验
- 响应式设计，自适应各种设备
- 支持相对路径部署

## 🚀 快速开始

### 环境要求
- Node.js 16+
- npm 或 yarn

### 运行游戏
```bash
# 进入游戏目录
cd snake_game

# 安装依赖
npm install

# 启动开发服务器
npm start

# 构建生产版本
npm run build
```

## 🎯 项目理念

我们的开发理念是**"经典创新"**：

1. **致敬经典**: 在大家熟悉的游戏机制基础上进行创新
2. **视觉升级**: 加入现代的视觉效果和用户体验
3. **玩法创新**: 在传统玩法中加入新的机制和系统
4. **技术驱动**: 使用现代web技术实现流畅的游戏体验
