# 光影之线 (Light Beam)

一个基于React的创意贪吃蛇机制游戏，以光束为主题的创新玩法。

## 🎮 游戏特色

### 创新玩法
- **光束机制**：控制一道不断延伸的光束在黑暗中穿梭
- **收集光点**：收集不同类型的光点来照亮世界
- **渐变效果**：光束具有美丽的渐变色彩和光晕效果
- **粒子系统**：收集和碰撞时产生炫酷的粒子效果
- **动态背景**：背景会随着游戏进程逐渐被照亮

### 视觉效果
- 炫酷的光束粒子效果
- 动态星空背景
- 收集光点时的光效动画
- 碰撞爆炸效果
- 玻璃态UI设计

## 🕹️ 游戏控制

### 键盘控制
- **方向键 / WASD**：控制光束移动
- **空格键**：暂停/继续游戏
- **R键**：游戏结束后重新开始
- **ESC键**：暂停游戏
- **Enter键**：开始游戏

### 触摸/鼠标控制
- **滑动**：在触摸屏上滑动控制方向
- **点击**：点击屏幕对应位置改变方向
- **双击**：暂停游戏
- **右键**：暂停游戏

### 移动端虚拟按键
- **方向按钮**：精确控制光束方向
- **暂停按钮**：暂停/继续
- **重新开始**：游戏结束后快速重启

## 🎯 游戏目标

- 收集蓝色光点获得基础分数
- 收集金色光点获得额外分数奖励
- 避免撞到墙壁或自己的光束轨迹
- 随着等级提升，游戏速度会加快
- 照亮整个黑暗世界

## 🚀 如何运行

### 环境要求
- Node.js 16+
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 开发运行
```bash
npm start
```

### 构建生产版本
```bash
npm run build
```

## 🛠️ 技术实现

### 核心技术
- **React 18**：现代化的UI框架
- **Canvas API**：高性能的2D图形渲染
- **RequestAnimationFrame**：流畅的游戏循环
- **响应式设计**：支持各种屏幕尺寸

### 游戏架构
- **面向对象设计**：清晰的类结构
- **状态管理**：集中的游戏状态控制
- **事件系统**：灵活的输入处理
- **粒子系统**：动态的视觉效果

## 🎨 游戏机制

### 光束系统
- 光束由多个发光段组成
- 每段具有独立的光强度
- 光强度随时间衰减产生渐变效果
- 收集光点时光束会增长

### 光点系统
- **普通光点**：蓝色，基础分值1
- **奖励光点**：金色，分值5，脉冲效果
- 光点具有脉动动画
- 收集时产生粒子爆炸效果

### 难度递增
- 随着等级提升，游戏速度加快
- 光点数量增加
- 需要更高的操作技巧
